# Otets CLI

> Клиент для чтения постов из социальной сети ИТД прямо в терминале.

## Особенности
- Прямое подключение к API ИТД (без тяжелого рендеринга SPA)
- Цветной форматированный вывод (Rich UI)
- Поддержка пагинации и навигации
- Чистая архитектура и модульность

## Установка

Требуется Python 3.8+

bash
git clone https://github.com/твой-ник/otets-cli.git
cd otets-cli
pip install -r requirements.txt

## Запуск
python src/main.py

## Управление

n — следующая страница
p — предыдущая страница
q — выход
